# 隐私与本地数据

szElectricityMeter 没有开发者服务器、账号系统、遥测或广告 SDK。正常模式只向配置所用的南网电量查询端点请求数据。源代码与安装包不内置个人凭证。

## 保存什么

| 数据 | 存放位置 |
| --- | --- |
| Token | macOS 钥匙串，服务 cn.shenzhenmeter.credentials，条目 csg-token |
| 电表名称、区域/客户/计量点 ID、电价与偏好 | ~/Library/Application Support/ShenzhenMeter/settings.json |
| 月度累计、日用量、温度、可用的分时总量与查询时间 | 同目录 usage-<账户哈希>.json，最多 24 个月 |
| 窗口位置、阶梯通知去重标记 | 当前 App 的 macOS 偏好存储 |

为兼容早期本地版本，存储目录和 bundle ID `cn.shenzhenmeter.app` 保持原命名。账号哈希用于隔离缓存，不是对用电数据的加密。目录权限为 700、写入文件为 600；同一登录用户下有相应权限的程序仍可能读取配置和缓存。

Token 不回显，不写入缓存。请求使用 HTTPS，不跟随重定向；只保留解析后的必要字段，不保存原始响应中的设备编号和表号。

## 演示模式

以 `--demo` 启动时，使用程序生成的虚构数据，在加载本机配置和读取钥匙串之前进入独立分支。演示设置仅存在于内存；不发起接口请求、注册登录项或请求通知权限。

## 清理

先在设置关闭登录启动，再退出 App。移除本地数据目录可清理设置和缓存；在“钥匙串访问”中查找服务名称并删除对应条目，可移除 Token。卸载 App 本身不会自动删除这些数据。
