# 电价、阶梯与预测

默认参考深圳市居民生活电价表的价格（元 / 度）：一档 `0.6542`、二档 `0.7042`、三档 `0.9542`。夏季（5–10 月）阈值 `260 / 600` 度，非夏季 `200 / 400` 度。电费是分段累加，跨档不会把之前用电按新价格重算。达到恰好 260 / 600 度时，界面档位表示**下一度电适用的档位**。

参考价目表注明不含政府性基金及附加，App 默认附加为 0；实际账单单价可能不同，请在设置中校准。可核对 [深圳市发展改革委价目表](https://fgw.sz.gov.cn/attachment/1/1460/1460239/11394935.pdf)。App 当前按自然月估算，不自动识别特殊抄表周期、多人口优惠、免费电量、退款或账单舍入规则；特殊用户可调整阈值，最终以供电账单为准。

峰谷默认第一档为峰 `1.1121`、平 `0.6542`、谷 `0.2486` 元 / 度，在基础分时电费上叠加第二档 +0.05、第三档 +0.30 元。只有峰 / 平 / 谷三段电量完整且总和匹配月累计，才提供峰谷电费估算。接口没有完整分时数据时显示缺失，不把普通阶梯金额当作峰谷金额。普通阶梯用户单纯错峰不会降低每度单价。

预测采用「月累计 ÷ 已发布的完整天数 × 月总天数」，至少需要 3 天、从月初连续完整的日数据且合计与月累计相符。数据落后超过两天时停止预测。预算按数据截止日之后的天数计算，**包含尚未出数据的日期**，并非实时剩余额度。节电模拟同样从数据截止日之后估算，无法回溯修改已发生的用电，也不预测天气或设备行为。估抄数据会标记。
